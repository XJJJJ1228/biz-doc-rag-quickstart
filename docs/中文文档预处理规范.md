# 中文文档预处理规范
## 目标
对PDF/Word导出的原始文本做标准化清洗，去除噪声，修复分页带来的文本断裂，输出适合RAG切片的干净中文文本。

## 一、噪声过滤规则
1. 删除页眉、页脚、页码，例如：`第 1 页 共 10页`、`XX公司内部文件`重复页眉
2. 删除多余空行、连续空格、制表符
3. 清理文档换行：分页符导致一句话被拆成两行，自动合并
4. 清理表格碎文本：表格导出产生零散无意义短句
5. 统一符号：全角括号、数字、标点统一，去除不可见特殊字符
6. 过滤纯数字、无意义单行（单独页码、分隔线）

## 二、中文文本修复规则
1. 段落合并：当一行末尾没有句号/分号/问号，下一行是正文，则合并两行
2. 保留标题标记：识别一级、二级标题（如 1.、1.1、一、（一）），标题单独保留，作为元数据
3. 不修改原文语义：清洗只删噪声，不修改业务文字内容

## 三、输入输出
输入：PDF/Word复制导出的原始txt文本
输出：干净连续的正文文本，保留标题层级，无多余噪声，用于下一步语义切片。

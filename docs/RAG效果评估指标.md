# RAG问答效果评估指标体系
分为人工评估 + 脚本辅助幻觉检测

## 评估维度（满分10分）
1. 信息召回（3分）：是否检索到原文对应答案片段
2. 幻觉程度（3分）：是否编造原文不存在信息
    - 0分：大量编造信息
    - 3分：完全没有编造
3. 引用准确性（2分）：回答引用的原文片段和文档一致
4. 信息完整性（2分）：关键信息没有遗漏

## 评估流程
1. 准备测试问题集，每个问题预先标记原文答案位置
2. 把问题送入RAG问答，获取模型回答
3. 人工打分；脚本自动检测回答文本是否存在原文以外内容，标记疑似幻觉
4. 记录分数，迭代优化切片策略与提示词

## 幻觉判定标准
- 硬幻觉：文档完全没有的事实、数字、条款
- 软幻觉：语义歪曲，对原文错误解读

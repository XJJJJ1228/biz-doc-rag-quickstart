# 语义切片策略
> 对比方案：固定字符切片 VS 中文语义切片

## 固定字符切片缺点（通用RAG常用方案）
按固定字符数切割文本，不看句子边界，容易把完整一句话从中间切断，语义碎片化；丢失章节标题上下文，检索片段缺少背景信息。

## 本项目混合语义切片方案
1. 第一层粗分割：根据标题（1.、1.1、一、（一））拆分大章节，记录章节名称作为元数据
2. 第二层细分割：在章节内部，以中文句号。分号；问号？感叹号！作为语义边界切分句子
3. 长度约束：语义块控制在 300~600字符；如果单个语义单元过长，在逗号、顿号处谨慎切分，优先保证语义完整
4. 元数据绑定：每一个切片chunk附带：章节标题、来源文件名
